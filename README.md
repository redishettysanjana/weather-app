# Worldwide Weather App 🌦️

A responsive weather application that allows users to explore weather conditions across the world. Search for cities, countries, continents, and even remote locations such as Antarctic research stations.

## ✨ Features

- **Worldwide Search:** Search for cities, countries, continents, and remote locations.
- **Location Suggestions:** Get suggestions while typing.
- **Country & Continent Browsing:** Explore countries by continent and cities within countries.
- **Current Weather:** View temperature, weather conditions, humidity, wind speed, and precipitation.
- **5-Day Forecast:** Check upcoming weather conditions.
- **Temperature Conversion:** Switch between Celsius (°C) and Fahrenheit (°F).
- **Dynamic Themes:** Background changes according to weather conditions.
- **Error Handling:** Handles network errors and temporary API service issues.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Open-Meteo Weather API
- Open-Meteo Geocoding API
- REST Countries API
- CountriesNow API

## 🌍 APIs Used

| API | Purpose |
|---|---|
| Open-Meteo | Current weather and forecasts |
| Open-Meteo Geocoding | Search and locate places |
| REST Countries | Retrieve country information |
| CountriesNow | Retrieve city lists by country |
